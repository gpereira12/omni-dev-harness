# 👑 Master Integration Protocol (MIP)

Follow this 7-phase flow when initiating any new system, major refactoring, or architectural review:

## Phase 1: UX & Behavioral Strategy
- Identify primary Actor, Target Action, and core business utility.
- Ensure balance between Google-Utility (clarity, performance) and Apple-Aesthetics (refinement, spacing).

## Phase 2: System Architecture & Stack Selection
- Monolith vs Microservices vs Modular Monolith.
- Apply CAP theorem tradeoffs (Consistency vs Availability).
- Choose backend (NestJS, Rust, Rails, Go) and frontend (Next.js, Vite, Astro, React Native, Swift).

## Phase 3: AI & Intelligence Layer
- Evaluate if RAG, autonomous agents, or MCP servers are required.
- Define model tiering (Flash vs Pro) and tool boundaries.

## Phase 4: Data & Backend Engineering
- Design relational (PostgreSQL) or document schemas.
- Plan API conventions (18 REST Rules, gRPC, or GraphQL).
- Apply Hexagonal Architecture, Transactional Outbox, or CQRS where appropriate.

## Phase 5: Design System & Frontend / Mobile
- Define design tokens (HSL color harmony, fluid typography).
- Enforce resilient state handling (Error Boundaries, Skeletons, 4-State Async).

## Phase 6: DevOps, Cloud (GCP) & Reliability
- Plan containerization on Google Cloud Run, Cloud SQL, and Secret Manager.
- Define zero-downtime migration strategy and Testing Pyramid (Unit, Integration, Playwright E2E).

## Phase 7: Analytics, Security & Governance
- Setup Cloud Logging, Error Reporting, and audit trails.
- Enforce GDPR/LGPD compliance and RBAC access controls.
